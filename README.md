# M.S Consultoria — site React/Vite

## Requisitos
- Node.js LTS instalado (inclui npm).

## Rodar no Windows CMD
1. Extraia o ZIP.
2. Abra o CMD dentro da pasta `ms-consultoria-site`.
3. Execute `npm install`.
4. Execute `npm run dev`.
5. Abra no navegador o endereço local mostrado no terminal (normalmente http://localhost:5173).

Para gerar a versão de produção: `npm run build`.

Observações: não há tags reais de Google Ads/Analytics configuradas. Revise as políticas e teste o bloqueio de rastreadores antes de publicar. O formulário direciona para WhatsApp, não envia para um servidor.
